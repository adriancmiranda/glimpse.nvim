 glimpse.nvim - Inline image preview for Neovim.

 Renders images directly in the terminal via Kitty Graphics Protocol,
 with fallback to Sixel and external panes (WezTerm, iTerm, tmux).

 Basic usage:
 >lua
   require('glimpse').setup()
 <

 Default keymaps (Oil.nvim):
   `<leader>p` - Preview image side by side (does not change cwd)
   `;`         - Open image (may change cwd when configured)
   `q`         - Close image buffer

 Supported terminals:
   Kitty, Ghostty (inline), WezTerm (pane), iTerm2 (pane),
   xterm/foot/mlterm (Sixel via tmux)

GlimpseConfig                                                    *GlimpseConfig*
     @see credits https://github.com/folke/snacks.nvim (snacks.image)
     @see source https://www.reddit.com/r/neovim/comments/1e1txpz/some_fun_with_oilnvim_and_wezterm_for_image/
     glimpse.nvim configuration.

    Fields: ~
        {strategy?}            ("auto"|"inline"|"pane")     Rendering method (default: 'auto')
        {pane_position?}       ("right"|"bottom")           External pane position (default: 'right')
        {pane_size?}           (number)                     External pane size in percent (default: 40)
        {inline?}              (GlimpseInlineConfig)        Inline rendering options
        {keys?}                (GlimpseKeysConfig)          Configurable keymaps
        {debounce?}            (GlimpseDebounceConfig)      Debounce timings in ms
        {cell_size?}           (GlimpseCellSizeConfig)      Estimated terminal cell pixel size
        {cache_dir?}           (string)                     Cache directory for converted images
        {cache_max_age_days?}  (number)                     Days to keep cached files (default: 7)
        {max_file_size?}       (number)                     Maximum bytes to process (default: 50MB)
        {loading_text?}        (string)                     Text shown while loading
        {formats?}             (string[])                   Supported image extensions
        {integrations?}        (GlimpseIntegrationsConfig)  Plugin integrations


GlimpseInlineConfig                                        *GlimpseInlineConfig*

    Fields: ~
        {rerender_on_tab?}  (boolean)  Re-render when returning to an image tab (default: true)
        {close_with_q?}     (boolean)  Map a key to close the image buffer (default: true)


GlimpseOilConfig                                              *GlimpseOilConfig*

    Fields: ~
        {enable?}      (boolean)                              Keymaps in Oil.nvim (default: enabled)
        {follow_cwd?}  (boolean)                              Follow image directories when opening with `;` in Oil (default: true)
        {open?}        (string|fun(filepath:string):integer)


GlimpseTelescopeConfig                                  *GlimpseTelescopeConfig*
    or custom logic returning the opened buffer (default: 'edit')

    Fields: ~
        {enable?}          (boolean)                Preview in Telescope (default: enabled)
        {pickers?}         (string|string[]|table)  Telescope pickers that receive Glimpse previews
        {follow_cwd?}      (boolean)                Follow image directories when previewing in Telescope (default: false)
        {previewer?}       (table)                  Custom Telescope previewer instance
        {previewer_opts?}  (table)                  Options passed to the Glimpse previewer factory
        {image?}           (boolean)                Enable image previews (default: true)
        {video?}           (boolean)                Enable video previews (default: true)
        {archive?}         (boolean)                Enable archive previews (default: true)
        {sqlite?}          (boolean)                Enable SQLite previews (default: true)
        {font?}            (boolean)                Enable font previews (default: true)
        {cert?}            (boolean)                Enable certificate previews (default: true)
        {key?}             (boolean)                Enable key previews (default: true)
        {binary?}          (boolean)                Enable binary previews (default: true)


GlimpseKeysConfig                                            *GlimpseKeysConfig*

    Fields: ~
        {preview?}  (string)  Keymap for preview in Oil (default: '<leader>p')
        {open?}     (string)  Keymap for opening an image in Oil (default: ';')
        {close?}    (string)  Keymap for closing the image buffer (default: 'q')


GlimpseDebounceConfig                                    *GlimpseDebounceConfig*

    Fields: ~
        {prefetch?}  (number)  ms before pre-converting on cursor move (default: 200)
        {resize?}    (number)  ms before re-rendering on resize (default: 100)


GlimpseCellSizeConfig                                    *GlimpseCellSizeConfig*

    Fields: ~
        {width?}   (number)  Estimated pixels per column (default: 20)
        {height?}  (number)  Estimated pixels per row (default: 40)


GlimpseIntegrationsConfig                            *GlimpseIntegrationsConfig*

    Fields: ~
        {oil?}        (boolean|GlimpseOilConfig)                         Keymaps in Oil.nvim (default: true)
        {neotree?}    (boolean|{enable?:boolean,auto_preview?:boolean})  NeoTree integration config
        {telescope?}  (boolean|GlimpseTelescopeConfig)                   Preview in Telescope (default: true)
